# Get-PsUiIconFont

## SYNOPSIS
Returns the currently active icon font name.

## SYNTAX

```
Get-PsUiIconFont [<CommonParameters>]
```

## DESCRIPTION
Returns the name of the icon font PsUi is currently using for glyph rendering (e.g. "Segoe MDL2 Assets" or "Segoe Fluent Icons").

## EXAMPLES

### EXAMPLE 1
```
Get-PsUiIconFont
# Segoe Fluent Icons
```
